              What’s new

              • Recent PDFs Reopen a local copy with your latest saved edits.
              • Pages, Find, and Save as Manage pages visually, jump to matching text, and choose an export format.
              • Mobile editing Undo and Redo stay in the top toolbar and keep your place in the PDF.
              • Fonts and signatures Choose a font for text, or place a typed or hand-drawn signature.
              • Move PDF content Drag selectable text or pick up a page area, including artwork and scanned text.
              • Mobile and desktop Pinch to zoom in Select mode on phones, or install the editor as a web app.
              • Versions Save named checkpoints and restore them in the same browser.
              • Edit PDF text Select existing text, cover it, and add a replacement you can move.
              • Export pages Extract or reorder pages while keeping your edits.
              • Auto-organize Review extracted text, sort or filter it, and export it to CSV or PDF.

              Install PDF Editor

              Open the hosted editor in a browser that supports installing web apps.

              1. On Windows, open the Chrome or Edge menu and choose the option to install this site as an app.
              2. On iPhone or iPad, open Safari’s Share menu and choose Add to Home Screen.
              3. On Android, open Chrome’s menu and choose Install app or Add to Home screen.
